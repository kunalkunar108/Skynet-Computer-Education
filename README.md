# Skynet Computer Education Website

A responsive institute website built with React, Vite, React Router and custom CSS.

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Pages
- Home
- About
- Courses catalogue with category filters
- Individual course detail pages
- Faculty
- Facilities
- Gallery
- Contact and admission enquiry

## Important content notes
- Course fees, durations and official syllabi are intentionally not invented. Students are asked to contact the institute for current details.
- Faculty names are included as provided; qualifications and subject specializations are not claimed.
- Gallery and facility images are illustrative stock images. Replace them with real institute photographs before launch.
- Certificate affiliation/recognition wording is intentionally conservative until the affiliating organization and supporting documents are added.
- Admission form opens WhatsApp with the student's enquiry. It does not store submissions in a database.
- No admin dashboard or Supabase backend is configured in this first frontend release.
